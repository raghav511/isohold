# Red team: trust failures

Each issue was reproduced with a failing check in `tests/test-redteam.js`, run against the unchanged app (`origin/main`), before it was fixed. The check now passes on Chromium (Android) and WebKit (iPhone). Run it with `node test-redteam.js`.
